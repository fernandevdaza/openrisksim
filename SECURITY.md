# Security policy

OpenRiskSim runs entirely in the browser: spreadsheets are processed locally and nothing is uploaded to a server.
The main risks are malicious spreadsheet files (e.g. crafted `.xlsx` that crash or hang the app) and supply-chain issues
in dependencies.

## Supported versions

Only the latest release and the version deployed at <https://fernandevdaza.github.io/openrisksim/> receive fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on <https://github.com/fernandevdaza/openrisksim/security>.

Include the steps to reproduce and, if possible, the file that triggers the problem. You should receive an answer within
a week. Reports in Spanish or English are welcome.
