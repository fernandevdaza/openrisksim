# Keyboard shortcuts

On macOS use <kbd>⌘ Cmd</kbd> instead of <kbd>Ctrl</kbd>. <kbd>Alt</kbd> is <kbd>⌥ Option</kbd>. The list is also in the app: **Help → Keyboard shortcuts**.

## Simulation

| Shortcut | Action |
|---|---|
| <kbd>Alt</kbd>+<kbd>R</kbd> | Run |
| <kbd>Alt</kbd>+<kbd>S</kbd> | Step |
| <kbd>Alt</kbd>+<kbd>X</kbd> | Reset |
| <kbd>Esc</kbd> | Stop (while simulating) |
| <kbd>Alt</kbd>+<kbd>A</kbd> | Define assumption |
| <kbd>Alt</kbd>+<kbd>F</kbd> | Define forecast |
| <kbd>Alt</kbd>+<kbd>D</kbd> | Define decision |
| <kbd>Alt</kbd>+<kbd>C</kbd> | Correlations |

## File and help

| Shortcut | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save .xlsx |
| <kbd>F1</kbd> | Quick start |
| <kbd>Esc</kbd> | Close the open dialog or tool |

## Spreadsheet

| Shortcut | Action |
|---|---|
| <kbd>F2</kbd> / double-click | Edit the active cell |
| Typing | Replace the cell's content |
| <kbd>Enter</kbd> / <kbd>Tab</kbd> | Commit and move down / right |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move up / left |
| <kbd>Esc</kbd> | Cancel editing |
| Arrows | Move the active cell |
| <kbd>Shift</kbd>+arrows | Extend the selection |
| <kbd>Ctrl</kbd>+arrows | Jump to the data edge |
| <kbd>Home</kbd> | Go to column A |
| <kbd>Ctrl</kbd>+<kbd>Home</kbd> | Go to `A1` |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | Scroll one screen |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select the whole sheet |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> | Copy / cut / paste (Excel compatible; pasting a single value over a range fills it) |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> (or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>) | Undo / redo |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Clear the selection contents |
| Right-click | Context menu (define assumption, forecast, decision; copy/paste/delete definition; clear contents) |

::: tip Browser shortcuts
Some browsers reserve <kbd>Alt</kbd> combinations (e.g. to open their menus on Windows or Linux). If a shortcut doesn't respond, click the sheet first to give the app focus, or use the ribbon buttons. Installed as an app (PWA) there are fewer conflicts.
:::
