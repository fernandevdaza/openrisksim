# Atajos de teclado

En macOS usa <kbd>⌘ Cmd</kbd> en lugar de <kbd>Ctrl</kbd>. <kbd>Alt</kbd> corresponde a <kbd>⌥ Option</kbd>. La lista también está en la app: **Ayuda → Atajos de teclado**.

## Simulación

| Atajo | Acción |
|---|---|
| <kbd>Alt</kbd>+<kbd>R</kbd> | Ejecutar |
| <kbd>Alt</kbd>+<kbd>S</kbd> | Paso a paso |
| <kbd>Alt</kbd>+<kbd>X</kbd> | Restablecer |
| <kbd>Esc</kbd> | Detener (mientras se simula) |
| <kbd>Alt</kbd>+<kbd>A</kbd> | Definir supuesto |
| <kbd>Alt</kbd>+<kbd>F</kbd> | Definir pronóstico |
| <kbd>Alt</kbd>+<kbd>D</kbd> | Definir decisión |
| <kbd>Alt</kbd>+<kbd>C</kbd> | Correlaciones |

## Archivo y ayuda

| Atajo | Acción |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Abrir |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Guardar .xlsx |
| <kbd>F1</kbd> | Guía rápida |
| <kbd>Esc</kbd> | Cerrar el diálogo o la herramienta abierta |

## Hoja de cálculo

| Atajo | Acción |
|---|---|
| <kbd>F2</kbd> / doble clic | Editar la celda activa |
| Escribir | Reemplazar el contenido de la celda |
| <kbd>Enter</kbd> / <kbd>Tab</kbd> | Confirmar y moverse abajo / a la derecha |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Moverse arriba / a la izquierda |
| <kbd>Esc</kbd> | Cancelar la edición |
| Flechas | Mover la celda activa |
| <kbd>Shift</kbd>+flechas | Extender la selección |
| <kbd>Ctrl</kbd>+flechas | Saltar al borde de los datos |
| <kbd>Inicio</kbd> | Ir a la columna A |
| <kbd>Ctrl</kbd>+<kbd>Inicio</kbd> | Ir a `A1` |
| <kbd>Re Pág</kbd> / <kbd>Av Pág</kbd> | Subir / bajar una pantalla |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Seleccionar toda la hoja |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> | Copiar / cortar / pegar (compatible con Excel; pegar un solo valor sobre un rango lo rellena) |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> (o <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>) | Deshacer / rehacer |
| <kbd>Supr</kbd> / <kbd>Retroceso</kbd> | Borrar el contenido de la selección |
| Clic derecho | Menú contextual (definir supuesto, pronóstico, decisión; copiar/pegar/eliminar definición; borrar contenido) |

::: tip Atajos del navegador
Algunos navegadores reservan combinaciones con <kbd>Alt</kbd> (por ejemplo, para abrir sus menús en Windows o Linux). Si un atajo no responde, haz clic primero en la hoja para darle el foco a la aplicación, o usa los botones de la cinta. Instalada como aplicación (PWA) hay menos conflictos.
:::
